# ZOZ AI Reusable Execution Templates

هذه المكتبة هي طبقة إعادة الاستخدام لمشاريع العملاء. الهدف هو أن يبدأ المشروع الجديد من وحدات جاهزة، ثم يتم تخصيص وربط المطلوب فقط.

## دورة التنفيذ

1. استقبال المشروع والمتطلبات.
2. تحويل المتطلبات إلى معايير قبول واضحة.
3. اختيار أقل مجموعة Templates تحقق المطلوب.
4. إعداد المتغيرات والبيانات الخاصة بالعميل.
5. ربط الخدمات الخارجية عند الحاجة.
6. الاختبار الوظيفي والأمني الأساسي.
7. فحص معايير القبول.
8. التسليم والتوثيق.

## الوحدات الحالية

- `project-intake`: استقبال المشروع وتحويله إلى خطة قابلة للتنفيذ.
- `dashboard`: أساس لوحة التحكم.
- `csv-import`: استيراد Excel/CSV والتحقق من البيانات.
- `api-integration`: طبقة موحدة للتكامل مع APIs.
- `automation-queue`: الطوابير والإرسال على دفعات وإعادة المحاولة.
- `whatsapp-cloud`: أساس WhatsApp Cloud API والقوالب والـwebhooks وحالات الإرسال.
- `crm-lite`: العملاء المحتملون والعملاء والمتابعة.
- `web-app`: أساس تطبيق ويب قابل للنشر.
- `quality-gate`: اختبارات وفحص جاهزية التسليم.

## قاعدة مهمة

لا يتم اعتبار Template جاهزًا لمشروع معين لمجرد وجوده في المكتبة. يجب اختبار المتطلبات الفعلية والاعتماد على حالة التكاملات والبيانات والصلاحيات الخاصة بالعميل.

## قاعدة الاستقلالية المالية

أي دفع أو شراء أو تحويل أو سحب أو استلام أموال يظل خلف موافقة بشرية صريحة، ولا يتم تجاوز هذه القاعدة عند تركيب أي Template.

## مثال: مشروع WhatsApp Dashboard

التركيب المقترح:

`project-intake` + `dashboard` + `csv-import` + `api-integration` + `automation-queue` + `whatsapp-cloud` + `quality-gate`

ثم يتم تخصيص الحقول والقوالب وبيانات Meta الخاصة بالعميل فقط.
